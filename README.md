# 🔒 FocusLock - 专注背稿锁机

> 把 distractions 都锁起来，专心背稿子！

一款 Windows 桌面小工具，帮助你在背稿/学习时锁定电脑，只允许白名单内的软件运行，杜绝分心。

---

## ✨ 功能特性

### 🎯 核心功能
- **⏱️ 定时专注模式**：自己设定专注时长，时间一到自动解锁
- **✅ 软件白名单**：只有白名单里的软件能用，其他一律打不开
- **🚫 进程守护**：每秒扫描一次，发现非白名单软件立刻关闭
- **🖥️ 全屏锁定遮罩**：深色遮罩 + 大倒计时，一目了然
- **🔔 完成提醒**：时间到了有提示音和恭喜动画

### 🎨 智能白名单管理（三合一）
- 📦 **从已安装软件添加**：自动扫描开始菜单+桌面，带图标勾选
- 🔄 **从运行中程序添加**：直接选择当前正在运行的窗口
- 📁 **浏览文件选择**：手动选择 exe 文件

### 🆘 安全保障
- **紧急解锁**：连续按 5 次 ESC 键触发紧急解锁
- **继续上次专注**：误触紧急解锁后，剩余时间自动保存，可随时继续
- **任务管理器自动恢复**：退出后自动恢复系统设置

## 🚀 快速开始

### 系统要求
- Windows 7 / 8 / 10 / 11
- .NET Framework 4.0 及以上（Windows 自带）

### 使用方法
1. 下载 `FocusLock.exe` 和 `config.xml` 到同一文件夹
2. 双击 `FocusLock.exe` 运行
3. 设置专注时长，点击「开始专注背稿」
4. 3秒倒计时后进入锁定模式
5. 时间到了自动解锁，或按5次ESC紧急解锁

## 📁 项目结构

```
FocusLock/
├── Program.cs              # 程序入口
├── MainForm.cs             # 主界面 + 倒计时提示
├── LockForm.cs             # 锁定界面（全屏遮罩+倒计时）
├── WhitelistForm.cs        # 智能白名单管理器
├── ConfigHelper.cs         # 配置读写（白名单、设置）
├── AppScanner.cs           # 软件扫描器（已安装/运行中/exe）
├── ProcessManager.cs       # 进程管理器（监控+杀进程）
├── KeyboardHook.cs         # 键盘钩子（拦截快捷键）
├── config.xml              # 配置文件
└── FocusLock.exe           # 编译后的可执行文件
```

## ⚠️ 注意事项

1. **第一次使用建议设置1分钟**，先熟悉操作
2. **紧急解锁方式**：连续快速按 5 次 ESC 键（2秒内）
3. 软件为绿色版，无需安装，直接运行
4. 默认白名单包含：WPS、汽水音乐、系统关键进程
5. 配置文件 `config.xml` 与 exe 放在同一目录
